# 🏠 Sakani Real Estate System

A full-stack real estate management platform built using React, Laravel, MySQL, and REST APIs.

---

## 📌 Overview

Sakani is a complete real estate platform that allows users to browse, search, and book properties while giving administrators full control over listings, categories, locations, reservations, and platform management through a powerful dashboard.

Designed with scalability, security, and modern development practices in mind.
